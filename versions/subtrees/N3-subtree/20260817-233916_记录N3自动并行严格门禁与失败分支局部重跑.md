- Problem: 多个 Agent 共用一棵树时，如何避免把全局 Next 误当作各自目标并互相覆盖？
- Approach:
  - 模型从根本目标和未决节点生成2–4个可审核分支，程序校验依赖、写集、保留路径和环。
  - 批准后按 ready frontier 在独立 worktree 写入；结果逐个进入 integration，不等待整批调查结束。
  - coordinator 核验实际差异并测试；结束审核接受后才应用到主工作区，冲突则拒绝覆盖。
  - worker 不写共享树；接受后由受限状态同步会话精炼受影响节点，GraphState 保留人类主视角。
- Input: 当前任务树、自动规划草案、用户开始审核和结束审核决定。
- Output: 自动并行状态机、git worktree 隔离、双审核界面、接受后节点同步与本地远程分发。
- Metrics: 草案阶段零写入；worker 越界必拒绝；依赖自动解锁；测试通过才可接受；主工作区并发修改不被覆盖。
