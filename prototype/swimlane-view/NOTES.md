# Block Flow Prototype (Scratch-style)

**Run:** `打开原型.cmd` → http://127.0.0.1:5199

泳道图已弃用，改为 **Scratch 式模块流**：从上到下执行，块可拼接。

## 块类型

| 块 | 颜色 | 作用 |
|----|------|------|
| 当…开始 | 蓝 | 脚本入口（帽块） |
| 任务 | 绿 | 任务树执行节点 |
| 方法参考 | 紫 | 公式/定义，附在任务下 |
| 如果…那么 | 橙 | C 形条件，内嵌子脚本 |
| 重复 N 次 | 黄 | C 形循环 |
| 一直重复 | 深橙 | 无限循环 |
| 结束 | 灰 | 脚本 cap |

## 自动生成

- 从 `empty-window.md` 解析节点
- 子步骤（N2a–d）自动包进「重复·依次执行子步骤」
- 公式块按边挂到对应任务下方
- **项目脚本** / **本次运行** 两种模式

## 手动

- 左侧面板插入 如果 / 重复
- 拖块改顺序；可拖入 C 形块内部
