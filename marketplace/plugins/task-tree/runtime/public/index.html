项目总览
链式 loop：Codex / Cursor 自动跑执行链

每轮 loop 的唯一执行依据是当前 Next 节点卡片上的「下一步思路」（节点字段 NextIdea，见 chain-step 的 stepMarkdown）。不要按 GraphState.NextPlan（「下一步」输入框）执行。Agent 可以读完整任务树、改树、跑命令；但一轮只完成 Next 节点上的这一项 NextIdea，不要跳去做 Chain 里后面的节点。

一、在项目页面配置（任务图 UI）

  1. 双击项目里的 打开任务图.cmd，确保本页已连上后台（地址栏端口即服务端口，当前：—）。
  2. 把节点设为 Next（◆ 按钮）后，在卡片上的 「下一步思路」 里写本轮 Codex 要做的一句可执行话（字段 NextIdea）。
  3. 点击节点标题旁的 ⊕ 加入底部执行链；拖动排序；高亮项 = 当前 Next。
  4. 左上角 自动推进（ChainAutoAdvance）：本步标记完成后，下轮自动把 Chain 下一节点设为 Next（你在新 Next 节点写好 NextIdea 再跑）。
  5. 「下一步」(NextPlan) 仅供 UI/备忘，loop 不读；保存后确认 Next、NextIdea、Chain 正确。

二、在 Codex / Cursor 里配置 loop

  1. 项目根目录打开 Agent（Codex 或 Cursor），工作目录必须是本项目根（含 AGENTS.md、task-tree.md）。
  2. 在 Cursor 聊天框粘贴下面命令启动 loop（推荐 3 分钟一轮）；Codex 同样粘贴为每轮指令或定时任务：

          
          
读哪些文件？ 每轮先用 chain-step 拿本步焦点（ROOT + 链上已走到的节点 + Next 的 NextIdea）。若需要全局上下文，可以再读完整 task-tree.md、改节点/边、运行 shell 命令——这些都是正常 Agent 能力。

          
不要做什么？ 一轮内不要擅自做完 Chain 里多个节点；不要按 NextPlan（「下一步」）执行；链结束或 shouldStopLoop 后不要继续 arm loop。
