## N3 - 让 Codex 同步维护任务图
- Position: 2052,950
- Size: 400,420
- Completion: 进行中
- Problem: 自动并行如何快速返回可审核分支，并在多 Agent、长期真实业务中持续抓住根本目标？
- Approach:
  - 模型在10秒总预算内生成2–4个分支；超时或重启中断则立即生成可审核保守草案。
  - 计划阶段只拒绝精确保留路径；运行后按实际改动拦截共享状态和越界文件。
  - worker 在独立 worktree 写入并测试；Codex 接受任务即回写入口，服务中断后保留已完成分支并续跑汇总。
  - 首屏只显示编号、自然名称、状态和一句结果；完整指令、写集与测试按需展开。
- Input: 当前任务树、本轮目标、可审核并行草案，以及开始与结束两次用户决定。
- Output: 带目标的自动规划、隔离并行、严格接受门禁、失败分支局部重跑与接受后节点同步。
- Metrics: 草案阶段零写入；点击后立即显示准备状态，Codex 接受任务后即出现入口；记录快照耗时并与86秒基线比较；受保护文件实际改动必拒绝；失败分支只重跑自身；审核前主工作区不变。
