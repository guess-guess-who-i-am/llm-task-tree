一键部署到其他项目
==================

【方式 A — 第一次在新项目（推荐）】

  把下面 2 个文件复制到目标项目根目录：

    deploy-task-tree.ps1
    部署任务图.cmd

  第一次还需要 kit 来源，任选其一：
    1) 把 llm-task-tree-kit 整个文件夹也复制到同一项目根目录
    2) 或设置环境变量 LLM_TASK_TREE_KIT=本机 llm-task-tree-kit 的完整路径

  然后双击 部署任务图.cmd

  成功后 kit 会缓存到：
    %USERPROFILE%\.llm-task-tree\template

【方式 B — 第二个及以后的项目（只复制小脚本）】

  只复制到项目根目录：

    deploy-task-tree.ps1
    部署任务图.cmd

  双击 部署任务图.cmd 即可（从缓存模板自动部署）

【脚本会自动完成】

  - 复制/更新 llm-task-tree/ 子目录
  - 运行 install（task-tree.md、AGENTS.md 合并、.gitignore、npm install）
  - 打开任务图浏览器界面

【已有 AGENTS.md】

  不会覆盖，只在末尾追加 llm-task-tree 协议块（若尚未追加）

【要求】

  - Windows + PowerShell
  - 已安装 Node.js
