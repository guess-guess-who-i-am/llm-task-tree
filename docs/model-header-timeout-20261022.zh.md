## 修复及权衡

只在单次模型请求的重试层处理：同一地址、同一模型出现响应头超时后，后续尝试的等待上限最多为基础值的两倍。默认单地址三次为60/120/120秒；正常路径仍为60秒，换地址或换模型不继承另一条路由的超时余量，三次尝试数量不变。该余量只在当前请求内部生效，不形成全局无限增长。

不重启Worker，不重跑已完成工具或Hook，不换模型，不重放部分流，不增加任务总时限或工具调用上限。真的无响应仍有终止出口，用户Stop会中断延长中的请求和等待。代价是完全失联时，单地址判失败可能比原先更慢；不能把等待策略称为网关提速或保证任务成功。

重试进度和attempt计时记录实际响应头预算；最终超时准确显示响应头阶段、实际尝试地址数量和各次预算。连接错误、鉴权错误、上下文错误和流停滞保留各自原有行为。
