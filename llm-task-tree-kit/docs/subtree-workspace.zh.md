# 子树独立画布

## 如何打开

直接点击折叠节点的「去到子树 →」，不必先展开、复制路径或打开新窗口。缩小到宏观视图时入口仍保留。在原有“任务图谱”标题栏也提供一个28px高的切换按钮：主树里显示「去到子树 →」，进入后变为「← 返回主树」，恢复原画布和焦点。选中折叠分支后可进入；只有一棵子树时自动提供入口。不再单独占用导航行，也没有特殊底色。鱼眼/透镜的子树入口仍保留。

切换使用 200ms 淡入加 18px 轻微位移，进入和返回的方向相反；只切换画布，侧栏和顶部工具不跟着晃动。浏览器没有原生视图过渡时使用 Web Animations；系统开启“减少动态效果”时直接切换。切换前先保存，读取和保存期间有状态提示，避免重复点击；读取失败保留原画布并允许重试。键盘焦点在进入后移到返回按钮，返回后移回入口。

子树路径可在返回按钮的提示中查看。标题栏右侧的「↗」可在独立窗口打开当前子树，但不是切换主树与子树的必经步骤。

子树沿用主树的节点与连线编辑器，可编辑标题和字段、增删节点、拖动、缩放、自动排版、适配视图、切换摘要和详文、使用鱼眼/焦点透镜、设定子树焦点、执行节点并续接其对话。

鱼眼节点标题右上角有小型「▶」直接执行图标，主树、子树和其它树都显示。先在“下一步”中填写任务，再点击：保存当前编辑，只执行正在看的节点，不拆分任务、不调用并行 Planner、不读取主树 Next 预设、不移动全局 Next。会打开该节点的执行对话框，显示输出并续接已有对话。未填写任务时聚焦输入框，不发送空请求。

子树仍是项目内 `subtrees/*.md` 文件，不另建 Git 仓库。保存写入子树文件，主树保持折叠。主树展开时读取更新后的子树内容。手动点击保存会备份旧版到子树版本列表；日常自动保存不制造大量版本。

## 修复了什么

此前子树虽能显示完整画布，但焦点缓存与主树共用，刷新会读回主树，关闭时未保存内容会请求主树保存接口，透镜执行也可能启动主树的下一节点。本次按当前工作区隔离缓存、读取和保存目标；子树保存保留 Fold root 标记，新增编号带折叠根前缀，减少与主树裸编号碰撞。工作区切换会等待正在进行的保存；保存期间又输入的新内容继续落盘后才切走，不把旧请求返回当成最新编辑已保存。

## 目前边界

“独立”指图编辑工作区，不是隔离代码目录。项目级执行流程、自动并行 Planner、知识库和模型配置仍属于整个项目；子树里不能再折叠/展开嵌套分支，需要返回主树操作。同一子树开多个窗口同时整文件编辑，尚无三方合并，可能发生后保存覆盖；独立窗口本身不提供写入隔离。新增编号前缀也不等于分布式唯一 ID。
