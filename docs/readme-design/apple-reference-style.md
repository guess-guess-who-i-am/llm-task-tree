# README 视觉风格提取

参考样本：用户提供的 Apple 官方产品页桌面与移动截图，覆盖 iPhone、macOS、Apple Intelligence 等页面。

## 可复用的设计原则

1. **先主张，后说明**：首屏只给产品名、一句核心承诺和一个主要画面，不在开头堆徽章、参数或功能清单。
2. **产品画面占主导**：真实界面承担解释任务；文字负责指出读图角度，不重复画面中的全部信息。
3. **一段只讲一件事**：每个功能段使用短标题、一句说明和一张大图，按“全局 -> 主干 -> 焦点”递进。
4. **留白建立层级**：白色与浅灰背景交替，段落间距明显大于段内间距；减少边框、卡片和装饰。
5. **克制的色彩**：黑、白、灰为底，仅让任务图本身的绿色主线和状态色成为强调。
6. **稳定的横屏媒体**：桌面画面保持 16:10 或 16:9，不把宽屏产品截图裁成竖向拼贴。
7. **动效服务于理解**：演示只呈现项目总览、语义缩放、焦点透镜和执行流程之间的切换，不做无信息的镜头运动。

## README 落地约束

- GitHub Markdown 无法复刻网页滚动动画，因此用大幅横屏图片建立节奏，用可点击封面打开短 WebM 演示。
- 顶部移除徽章墙和三联缩略卡，避免首屏像插件目录。
- 安装、协议、仓库结构和开发命令保留，但下沉到产品叙事之后；次要技术内容使用折叠区。
- 所有主视觉来自真实任务图页面；合成图只增加背景、标题、留白和播放按钮，不伪造产品能力。
